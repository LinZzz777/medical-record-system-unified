📐 LAYOUT STRUCTURE
═══════════════════════════════════════════════════════

CONTAINER:
- Screen frame: Rounded rectangle corners (28-32px border-radius)
- Safe area padding: 20px horizontal, 16px vertical minimum
- Content area: Max width 375-414px (iPhone standard)

CARD COMPONENTS:
- Card border-radius: 20-24px for main cards, 16px for nested elements
- Card padding: 16-20px internal spacing
- Card elevation: Soft shadow (0 8px 32px rgba(0,0,0,0.08))
- Glass effect: backdrop-filter: blur(20px), background: rgba(255,255,255,0.7)

INFORMATION HIERARCHY:
1. Primary data (hero metric): 48-72px font, bold weight, dark text
2. Section titles: 16-18px font, semibold weight
3. Body text: 14-15px font, regular weight, gray color
4. Captions/labels: 12-13px font, medium weight, light gray
5. Micro text: 11px font, for timestamps and metadata

SPACING SYSTEM:
- Consistent 8px grid system (8, 16, 24, 32, 48, 64px)
- Generous white space between sections (24-32px)
- Tight grouping within cards (8-12px between related elements)
- Bottom navigation area: 80-90px height including safe area

️ INTERACTIVE ELEMENTS
═══════════════════════════════════════════════════════

BUTTONS:
- Primary CTA: Full-width or large, height 48-52px, border-radius 26px
  * Background: #007AFF solid or gradient
  * Text: White, 16px, weight 600
  * Shadow: 0 4px 12px rgba(0,122,255,0.3)
  
- Secondary Button: Height 44-48px, border-radius 22px
  * Background: rgba(255,255,255,0.8)
  * Border: 1px solid rgba(0,0,0,0.1)
  * Text: #1D1D1F, weight 500

- Icon Button: 36-44px circular, backdrop-blur background
  * Background: rgba(255,255,255,0.5) with blur
  * Hover: Scale 1.05, brightness increase

- FAB (Floating Action Button): 56-64px circular, centered in nav bar
  * Background: #007AFF or gradient
  * Icon: White, 24px
  * Shadow: 0 8px 24px rgba(0,122,255,0.4)

INPUT FIELDS:
- Border-radius: 12-16px
- Background: rgba(255,255,255,0.6) with blur
- Border: 1px solid rgba(0,0,0,0.08), focus: #007AFF
- Height: 44-48px
- Padding: 12-16px horizontal

PROGRESS/CHART ELEMENTS:
- Progress bar: Height 4-6px, border-radius 3px, track: rgba(0,0,0,0.06)
- Circular progress: Stroke width 8-10px, rounded caps
- Mini bar charts: Rounded rectangles, gradient fills

TRANSITION ANIMATIONS:
- Card hover: TranslateY -2px, shadow increase, duration 200ms ease-out
- Button press: Scale 0.97, duration 100ms
- Page transitions: Slide with fade, duration 300ms cubic-bezier(0.4, 0, 0.2, 1)
- Skeleton loading: Shimmer gradient animation
- Number counters: Animate from 0 to value on scroll-into-view

FEEDBACK STATES:
- Active tab: Icon fill + color change + subtle scale (1.1)
- Selected card: Border highlight (#007AFF, 2px) + shadow increase
- Error state: Red accent (#FF3B30), shake animation optional
- Success state: Green checkmark, brief scale animation

 RESPONSIVE ADAPTATION

- Small (4.7" / 375x812): Compact spacing, 14px base font
- Standard (5.4" / 390x844): Default specifications
- Large (6.1" / 414x896): Increased padding, 16px base font

ADAPTATION RULES:

- Scale padding proportionally (min 16px, max 24px horizontal)
- Font sizes: Use clamp() or responsive type scale
- Grid columns: Single column up to 500px, optional 2-column for cards above
- Bottom nav: Always fixed, height adjusts to safe area
- Hero metrics: Responsive sizing, minimum 36px, maximum 72px

🌟 OVERALL AESTHETIC GUIDELINES
═══════════════════════════════════════════════════════

DESIGN PHILOSOPHY:
- Minimalist yet informative: Show only essential data, hide complexity
- Airy and spacious: Never crowded, breathe room between elements
- Premium feel: Subtle details matter (blur, shadows, gradients)
- Consistent: Unified corner radius, spacing, and color application

VISUAL EFFECTS:
- Glassmorphism: Frosted glass cards over gradient backgrounds
- Soft shadows: Never harsh, always diffused and ambient
- Gradient overlays: Subtle, never overwhelming
- Micro-interactions: Delightful but not distracting
- Depth: Layered UI with clear z-index hierarchy

THEME CONSISTENCY:
- Sky/nature inspired backgrounds when appropriate
- Blue as the trust and action color
- Rounded everything: No sharp corners in UI
- Light mode primary (consider dark mode variant)
- Professional but approachable
